# Fontes de assinatura

Estas fontes são usadas para renderizar a assinatura personalizada dos
administradores/professores nos certificados (PDF) e no preview do frontend.

Todas estão licenciadas sob a **SIL Open Font License 1.1** (ver `OFL.txt`),
que permite empacotar e redistribuir os arquivos junto ao software.

| Arquivo                  | Família        | Autores / origem                                             |
|--------------------------|----------------|--------------------------------------------------------------|
| GreatVibes-Regular.ttf   | Great Vibes    | The Great Vibes Pro Project Authors (googlefonts/great-vibes)|
| Allura-Regular.ttf       | Allura         | The Allura Project Authors (googlefonts/allura)              |
| Sacramento-Regular.ttf   | Sacramento     | Astigmatic (AOETI) — googlefonts/sacramento                  |
| AlexBrush-Regular.ttf    | Alex Brush     | The Alex Brush Project Authors (googlefonts/alex-brush)      |

Obtidas de https://github.com/google/fonts (ofl/).
